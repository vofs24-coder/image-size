About Image Size

Image Size is a simple online tool designed to help you resize images quickly and easily.

You can resize JPG, PNG and WebP images by changing their width and height in pixels. The tool also allows you to keep the original aspect ratio when changing the image size.

Simple and Private

Image Size is designed with simplicity and privacy in mind. Images selected for resizing are processed directly in your web browser rather than being uploaded to our server for image processing.

No Account Required

You can use the image resizing tool without creating an account or registering with Image Size.

Supported Formats

Image Size supports common image formats including JPG, PNG and WebP.
